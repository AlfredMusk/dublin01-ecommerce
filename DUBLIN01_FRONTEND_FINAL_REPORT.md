# DUBLIN/01 — Final front-end report

9 October 2026. Everything below was executed or measured on the local repository after the final corrections. What was not done is stated as such.

**Verdict: PASS — FRONT-END PORTFOLIO COMPLETE** (section 13). Front-end portfolio completion is not commercial production readiness.

## 1. Project summary

DUBLIN/01 is a front-end portfolio project: a complete storefront interface for a fictional sneaker and streetwear brand inspired by Dublin. There is no back end. Prices, stock, delivery terms, returns and VAT wording are illustrative, and the site says so.

## 2. Actual technology stack

| Layer | Reality |
|---|---|
| Pages | Static HTML generated by `scripts/build-html.mjs` (Node ≥ 20): 70 pages, including 32 product pages and 6 brand pages |
| Styles | Tailwind CSS 4.3.3 (CLI), tokens in `src/css/theme.css` |
| JavaScript | Native ES modules, no framework, no bundler |
| Data | `src/data/products.json` (32 products), `site.json`, `campaigns.json`; `localStorage` for bag, wishlist, history, consent |
| Tests | `node --test` (29 tests), syntax check |
| Dependencies | 4 development packages (`tailwindcss`, `@tailwindcss/cli`, `concurrently`, `serve`); none at runtime |

No React, Next.js, TypeScript or ESLint exists in this repository. None was added.

## 10. Corrected defects

- Free delivery: wording was "over €100" while the calculation was inclusive. Now "from €100" / "of €100 or more" everywhere, read from one value in `src/js/config.js`; a test covers the threshold.
- "Based in Dublin" claims (home, About, Terms, Privacy, FAQ, footer) replaced by "Inspired by Dublin" wording.
- Demo status made explicit: footer line, notice on every information page, checkout, account pages, newsletter, stock label.
- Search: a query such as `a'b"c` returned 29 products (single letters matched inside words). Single characters must now match a whole word; test added.
- Earlier in the day: layout shift on catalogue and product pages, product image preload, lighter images on phones, heading order, `robots.txt`, product copy that claimed unverified materials.

## 11. Remaining limitations

**By design (portfolio scope)**: no authentication, payment, orders, server inventory or email; `localStorage` only.

**Open data decisions for the owner**: items listed in section 4.

**Not verified**: the Safari application itself, physical devices, screen readers; performance on real hosting.

**Minor**: "Shop rain shells" opens a single product; product listings are rendered in the browser; no type checking or style linter.

**Third-party content**: brand names are references without affiliation; photographs are Unsplash images credited in `public/images/CREDITS.md`, with commercial rights not established.
